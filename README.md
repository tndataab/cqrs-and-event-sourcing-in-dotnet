
# CQRS and Event Sourcing in .NET

This repository contains the start code and solutions for my O'Reilly live webinar [CQRS and Event Sourcing in .NET](https://learning.oreilly.com/live-events/cqrs-and-event-sourcing-in-net/0636920080710/0636920080709/). It has everything you need to follow along with the code in the webinar.

## Getting started
The start code is in the [source/CQRS - Start project](https://github.com/tndataab/cqrs-and-event-sourcing-in-dotnet/tree/main/source/CQRS%20-%20Start%20project) folder.

## Background
The code is influenced by the code and tutorial on [cqrs.nu](https://cqrs.nu), a site I co-authored with my colleagues. CQRS (Command Query Responsibility Segregation) and Event Sourcing are patterns often used together with Domain-Driven Design (DDD), and are part of how I think about architecture in .NET.
